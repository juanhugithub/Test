# 个人工作台 v2.0

这是一个轻量、本地、默认安全的文件树整理工具，适合先梳理现有共享盘/个人盘资料，再通过 XMind 重构目录体系。

## 这次升级后的能力

1. **现代化工作台 UI**
   - 深色侧边栏 + 多标签页布局
   - 收藏节点栏
   - 搜索定位栏
   - 状态栏与日志区

2. **文件树预览**
   - 读取指定文件夹后，在 UI 中树状展示全部节点
   - 双击任意节点可直接打开文件或文件夹
   - 可快速搜索深层路径

3. **收藏节点**
   - 在树状图中右键任意节点 → 收藏该节点
   - 收藏后可在左侧栏直接打开并载入该节点的子树
   - 特别适合高频、深层、嵌套很深的目录

4. **XMind 兼容 Markdown**
   - 导出格式遵循 XMind Markdown 导入规则：文件以 `#` 开头
   - 一级标题为中心主题，二级标题为主分支，更深层用无序列表
   - 你可以先导出，再去 XMind 中整理，然后从 XMind 导出的 Markdown 重新创建目录

5. **从 Markdown 生长结构**
   - 根据 XMind / Markdown 结构，在目标目录创建新的目录树
   - 默认只创建文件夹，不删除、不覆盖，更安全

## XMind 兼容 Markdown 示例

```md
# 科室工作台/
## 01_项目管理/
- 重点项目/
  - 项目A/
  - 项目B/
## 02_文字材料/
- 通知/
- 请示/
- 汇报材料/
## 03_会议活动/
- 方案/
- 议程/
- 会务清单/
```

### 约定

- **文件夹**：名称后面加 `/`
- **文件**：名称后面不加 `/`
- 如果你只想生成文件夹系统，建议全部节点都写成以 `/` 结尾

## 推荐工作流

### 路线 A：先梳理旧资料，再重建新结构

1. 在“工作台”中读取现有共享盘/个人盘目录
2. 右键收藏常用深层目录
3. 切到“导出 XMind Markdown”导出结构
4. 用 XMind 打开并重新整理思路
5. 从 XMind 导出 Markdown
6. 回到“从 Markdown 生长”页载入并预览
7. 确认无误后创建新目录结构

### 路线 B：先在 XMind 里规划，再落地到硬盘

1. 直接在 XMind 里规划目录树
2. 导出 Markdown
3. 在本工具中载入 Markdown
4. 预览将要创建的路径
5. 一键生长新的目录体系

---

## 安全说明

- 本工具默认**不会删除**任何原有文件或文件夹
- 默认**不会覆盖**已存在内容
- 默认**不会创建文件**，只创建文件夹
- 收藏功能只是记录路径，不会移动原文件
- 如果要接入 AI，建议只在副本目录或个人加工区使用

## 命令行用法

### 导出为 XMind Markdown

```bash
python folder_tree_workbench.py export "D:\工作资料" "D:\工作资料_XMind结构.md"
```

### 只导出文件夹

```bash
python folder_tree_workbench.py export "D:\工作资料" "D:\目录树.md" --dirs-only
```

### 预览将要创建的路径

```bash
python folder_tree_workbench.py build "D:\目录规划.md" "D:\新工作台" --preview
```

### 创建新结构

```bash
python folder_tree_workbench.py build "D:\目录规划.md" "D:\新工作台"
```
